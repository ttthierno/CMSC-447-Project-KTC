# KonTraCk

How to Run the Frontend

1. Clone the repo - git clone https://github.com/ttthierno/CMSC-447-Project-KTC.git

2. Enter the project - cd CMSC-447-Project-KTC

3. Open the frontend - cd frontend

4. Install dependencies -npm install

5. Run the frontend - npm run dev

6. Open in your browser - http://localhost:5173/

7. Getting the Latest Changes - git pull
